Hermes Agent — Personal Assistant

What this application does

Hermes Agent is a personal AI assistant that helps me manage my daily information. It connects to my Google account to provide a consolidated morning summary of my calendar appointments and email, so I can start my day organized.

How it uses your data

This application accesses my own Google Calendar and Gmail data for the sole purpose of generating a daily summary of my appointments and messages. It reads calendar events and email to compile the summary, and may send a summary email to my own address. Data is used only for this purpose and is not shared with third parties.

Data access

The application requests access to:

  • Calendar: to read upcoming appointments and events
  • Gmail: to read recent messages and send the daily summary email

Privacy

This is a personal application used by the account owner. Access tokens are stored securely and used only to authenticate with Google services. No data is sold or shared.
